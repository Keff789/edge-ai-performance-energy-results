# Research transparency and source provenance

This collection separates recorded hardware measurements, derived analyses, software and historical audit material. A versioned source package or archived report is not automatically a new experiment. The [current-study description](current-study.md) names the evaluation populations and quality rule; the [research archive](archival_studies.md) identifies earlier snapshots.

## AI-assisted software development

The dissertation documents substantial assistance from **ChatGPT and Codex** during the development and revision of the ONNX Splitpoint Tool. The original disclosure, including the author's responsibilities, covered development tasks and verification measures, is preserved in [Appendix A: KI-gestützte Werkzeugentwicklung](../results/supplementary-studies/dissertation-appendix-20261111/source/4_appendix/A_ai_tool_development.tex) and in the [appendix supplement](../results/supplementary-studies/dissertation-appendix-20261111/README.md). The disclosure is intentionally not removed during the repository cleanup.

The author is responsible for the scientific claims, implementation acceptance, measurements and interpretation as described in that appendix. The repository's contents and the presence of a validation script do not, by themselves, prove that every historical run was repeated in this release.
