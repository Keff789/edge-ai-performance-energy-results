# English dissertation figure exports

`current-selection/` contains figures and tables regenerated by
`scripts/dissertation/export_thesis_selection.py` from the final published
measurements. Its manifest and validation record input hashes and unchanged
numerical results.

`figures/energy/` and `figures/methods/` contain the author's fixed English v48
publication PDFs. Their manifests record the original English source archive,
member paths, hashes and related repository evidence. They are byte-preserving
exports; the exact v48 composite plotting programs are not claimed to be
reproduced. Use `scripts/dissertation/export_frozen_thesis_figures.py` to export
or install these files with hash checks.

These English files complement the pre-existing German exports. The user-
supplied DrawIO bundle is maintained separately; no hardware measurements,
quality evaluations or fitting were repeated for this presentation update.
