Use the [central reproduction command](../../scripts/split-inference/README.md) with Python 3.12.3 and the existing pinned dependencies:

```bash
python3.12 -I -B scripts/split-inference/reproduce.py \
  --output ../split-analysis-r22 --publication mlsys-r22 --verify
python3.12 -I -B scripts/split-inference/reproduce.py \
  --output ../split-analysis-r22-numeric --publication mlsys-r22 --numeric-only --verify
```

Run these commands from the repository root in the prepared environment. The default invocation also includes `mlsys-r22`. Numerical mode generates all numerical payloads and TeX tables without Matplotlib or LaTeX. [Compact profile inputs and provenance](../../results/split-inference/publication-inputs/mlsys-r22/README.md) supply the additional evidence; models, datasets and large source archives are unnecessary for the normal offline run.
