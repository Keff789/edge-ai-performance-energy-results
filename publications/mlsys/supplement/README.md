# Complete MLSys supplement

[Read the supplement](MLSys_Supplement.pdf) or download its [LaTeX build sources](source.zip). The supplement supplies the full explanatory methods and results, including runtime settings, quality/audit decisions, scheduling protocols and energy acquisition.

The numerical figures and tables are generated by the [R22 publication profile](../../../results/split-inference/publications/mlsys-r22/README.md). Original audit records and additional scheduling source evidence are linked from the [MLSys entry point](../README.md).

Build the source ZIP with `latexmk -pdf supplement.tex`. No hardware or model compilation is required. The supplement is an author-visible working document.
