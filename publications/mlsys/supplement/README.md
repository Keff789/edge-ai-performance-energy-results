# Complete MLSys supplement

[Read the supplement](MLSys_Supplement.pdf) or download its [LaTeX build sources](source.zip). This working revision includes the complete RQ2 shortlist-budget analysis, alongside the runtime settings, quality and artifact audits, scheduling protocols and energy acquisition.

Section H.1 reports exact and near-optimal Native recovery, actual trial counts and random-selection success probabilities. Section J extends all five graph rules to complete rankings and every shortlist size. The deployment and graph-score measurement sets retain their own Native reference rates. The source archive contains only the files needed to compile this supplement.

The existing numerical figures and tables are generated by the [frozen R22 publication profile](../../../results/split-inference/publications/mlsys-r22/README.md). The new figures and budget table come from the [complete RQ2 analysis](../../../results/supplementary-studies/rq2-all-cuts-20261020/README.md), with its [generator and reproduction command](../../../scripts/supplementary-studies/rq2-all-cuts-20261020/README.md). Analysis commit: `9a7d3754691f0d54646e789f485d1565c87b268a`.

Original audit records and scheduling source evidence are linked from the [MLSys entry point](../README.md).

Build the source ZIP with `latexmk -pdf supplement.tex`. No hardware or model compilation is required. The supplement is an author-visible working document, not a claim of submission or acceptance.
