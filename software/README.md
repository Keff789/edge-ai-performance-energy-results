# Software and measurement tools

The offline split evaluator, energy-analysis programs and ONNX Splitpoint Tool are separate software components. The current main dataset includes DeepX Native A4 observations from tool version 2.95.5. A [selected frozen A4 source excerpt](deepx-native-a4-2.95.5/README.md) accompanies those observations. The complete v2.94.0 archive remains available for historical measurements and the endpoint reconstruction study.

## ONNX Splitpoint Tool

The [ONNX Splitpoint Tool](https://github.com/Keff789/ONNX-Splitpoint-Tool) analyses ONNX graphs, exports split candidates, and supports validation, performance and energy workflows on heterogeneous edge hardware.

The A4 measurements use **2.95.5**. The [selected source excerpt](deepx-native-a4-2.95.5/README.md) comes from the final verified source snapshot of 16 October 2026. Its ordinary manifest describes 2,283 release files. The asynchronous runtime and remote execution modules included here have identical recorded source hashes across the frozen continuation snapshots; final reporting/import code is identified separately. The final snapshot is an uncommitted source state based on `db729b9…`; that commit alone does not identify the A4 code.

The preserved historical full source is **2.94.0**, committed as [`db729b9fcde00e4bcadf9200d43282977d7bf1cc`](https://github.com/Keff789/ONNX-Splitpoint-Tool/commit/db729b9fcde00e4bcadf9200d43282977d7bf1cc). This was the selected public `main` on 14 October 2026. Its original version remains applicable to the historical records and source-derived functions that cite it.

For the preserved 2.94.0 revision, use its [README and GUI entry points](https://github.com/Keff789/ONNX-Splitpoint-Tool/blob/db729b9fcde00e4bcadf9200d43282977d7bf1cc/README.md#start-the-gui), [startup/installation script](https://github.com/Keff789/ONNX-Splitpoint-Tool/blob/db729b9fcde00e4bcadf9200d43282977d7bf1cc/start_gui.sh), and [dependency declarations](https://github.com/Keff789/ONNX-Splitpoint-Tool/blob/db729b9fcde00e4bcadf9200d43282977d7bf1cc/pyproject.toml). Accelerator SDKs, drivers, models and datasets require their own setup. Hardware workflows are separate from the offline analysis in [scripts](../scripts/).

The complete [v2.94.0 source archive](ONNX-Splitpoint-Tool_v2.94.0_db729b9fcde00e4bcadf9200d43282977d7bf1cc_source.tar.gz) contains the committed source and original MIT license, without Git history or local working changes. It contains 2,240 files (16,730,032 compressed bytes); SHA-256: `47afcaab6c61a7a289a4c6cea395a8679668efcda2f747ed5e126bed499dddb7`. The archive preserves the original source, including historical example and fixture paths. It does not contain accelerator SDKs or compiled models.

Historical measurement metadata retains its original software versions. Exactly 75 DeepX Native identities in the current main dataset use the A4 replacement cohort; the other 375 direct observations and all original quality selections retain their recorded provenance. The v2.94.0 archive and the selected 2.95.5 excerpt have different scopes. The historical preacceptance ZIP is not the final measured-source evidence. Neither source collection is needed to redraw the main figures from compact inputs.
