# Historical vendor projection

These inputs retain the manuscript's THESIS20 population: 588 coverage records, 560 quality records and 228 Native suffix exclusions. Coverage, completion pairs and Native cases reuse the existing THESIS20 tables through internal relative links. Their CSV records are identical; the manuscript used LF line endings and a trailing blank line. The original provenance check reconstructs that text serialization when checking shared files.

`deep_analysis/tables/quality_effects.csv` shares the same 560-row table as the manuscript review. The seven TensorRT Full companion rows have the same values and policy fields as their canonical Full rows and are excluded from the 42 unique Full quality results. Compiler completion, Native completion and quality eligibility are distinct populations. This historical projection does not replace the current Refresh16 results.
