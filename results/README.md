# Results directory guide

The results are organized by experimental area, while a few dated folders retain frozen historical snapshots. **Use the current analysis links below before exploring dated archives.** Keeping the historical paths prevents existing manifests and cross-references from becoming misleading.

| Directory | Role | Starting point |
|---|---|---|
| `split-inference/` | Recorded deployment results, methods and selected comparison tables | [Split inference](split-inference/README.md) |
| `energy-measurement/` | Energy recordings, reconstruction, calibration and measurement evaluation | [Energy measurement](energy-measurement/README.md) |
| `supplementary-studies/` | Current selection analyses alongside preserved auxiliary and historical studies | [Current analyses](supplementary-studies/README.md) · [Historical index](../docs/archival_studies.md) |
| `publication-builds/` | Versioned generated artifacts for the paper and dissertation; **not a separate measurement cohort** | [Current build snapshot](publication-builds/generic420-20261027/README.md) |

## Current split-selection source of truth

The machine-readable [active-results record](ACTIVE_GENERIC420.json) identifies the RQ2, RQ3, staged-selection and publication-build directories, their scope and source-snapshot identifiers. See the [current study overview](../docs/current-study.md) for the differences among 420 Generic candidate configurations, 204 Generic–Native paired cuts and 42 Full alternatives. Overlapping candidates must not be summed as separate observations.

**Preservation rule:** Dated folders, audit records and duplicate publication exports are retained because historical checksums and reproduction references refer to those exact file paths. A smaller navigation surface is not the same as deleting research evidence. The [archive index](../docs/archival_studies.md) explains which records are historical and where they belong in the workflow.
