# Reconstruction and PSD source

`energy_paper_checks.py` is the supplied native/all-15 reconstruction program v1.0.1. `psd/commonref/` is the original Common-Reference PSD Tool v0.9.0, located in the existing local energy-analysis checkout; it contains the native spectral, Welch, multi-workload and journal figure generators. Source configurations and the effective configurations used for the retained spectra are included. The v0.9.0 code retains its earlier analysis branches; the current primary selection is defined by the [result methods](../../../results/energy-measurement/METHODS.md).

These are offline analysis tools, not acquisition collectors. Raw waveforms and full-resolution NPZ inputs are external requirements; the compact review curves in this repository cannot replace them for PSD estimation. No waveform reanalysis was run during preparation. Original dependency pins are in [psd/requirements.txt](psd/requirements.txt). Only path prefixes/default locations were made portable; configure explicit external input and output locations before running them. The `external-measurements` and `external-analysis` paths are placeholders for user-supplied data, not included files.

The public result-export commands are documented one level [above](../README.md). The historical FP16 selection there uses pure numerical and plotting subsets of the original Common-Reference functions with bundled completed outcomes; it can redraw the 13-run spectra and rate curves without full-resolution arrays or raw waveforms. There is no automatic pipeline launch or install script here. Measurement collectors are separately available from the source repositories referenced by the recorded transformation evidence: [u.RECS collector](https://github.com/PercyJW-2/urecs-data-collector) and [power calculations](https://github.com/PercyJW-2/masterarbeit-helper-scripts). Their execution-bound identities are retained in the data where supplied; current collector code is not claimed to reproduce every earlier measurement state.
